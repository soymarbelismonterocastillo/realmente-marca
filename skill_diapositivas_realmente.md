## 💻 3. ESPECIFICACIONES TÉCNICAS DEL VISOR DE DIAPOSITIVAS
* **Formato:** Visor Web Interactivo HTML de diapositivas en formato 16:9.
* **Tipografías:** `'Playfair Display'` para títulos/frases y `'Outfit'` / `'Montserrat'` para cuerpo de texto.
* **Controles Integrados:** Botones Anterior / Siguiente, Modo Pantalla Completa, Cambio de Tema Claro/Oscuro y navegación por teclado (`←` / `→`).
