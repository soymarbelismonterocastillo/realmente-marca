## 🛠️ Automatización y Sincronización

Este repositorio se sincroniza automáticamente mediante la herramienta integrada **`github_helper.py`**, la cual ejecuta commits semánticos (`feat:`, `docs:`, `fix:`, `chore:`) respetando las mejores prácticas de Git y GitHub.
